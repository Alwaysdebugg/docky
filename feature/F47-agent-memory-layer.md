# F47 · Docky 作为 Agent 持久记忆层

> 一句话:把 docky 从"过程文档库"升级为编码 agent 的**标准长期记忆层**——结构化记住决策/约定/坑/偏好,带**显著度、衰减与自动召回**,让 agent 在对的时刻自动想起对的事。

## 战略定位(为什么这是旗舰级跃迁)

Agent 记忆是 Anthropic 关心的核心问题。docky 已经"按项目隔离地存过程文档"——这正是**长期记忆的天然载体**。把它显式建模为"agent memory layer",docky 就从一个工具跃迁为**任何编码 agent 都依赖的记忆基础设施**,与 Claude Code 形成互补的平台级能力。

## 背景与痛点

- F07 把文档**检索**成上下文包,但那是"按需拉取";**没有"记忆"的语义**:哪些是必须长期记住的决策/约定/坑?何时该主动想起?随时间如何衰减?
- 现状:agent 每次会话从零开始,反复踩同样的坑、违反同样的约定——因为**没有一个会自动召回的结构化记忆**。
- F03(状态/陈旧)、F44(使用度)、F20(写时去重)其实已经备齐"记忆生命周期"的原料,只差把它们组织成记忆模型。

## 目标 / 非目标

**目标**
- **结构化记忆**:在文档之上(或新增 `memory` 维度)建模 `decision / convention / gotcha / preference` 等记忆条目,带**显著度**(F44 使用度)、**衰减**(F03 陈旧/复审)、来源回链。
- **自动写回**:agent 经 MCP `remember(...)` 沉淀新学到的约定/坑(走 F20 去重合并,避免重复记忆)。
- **自动召回**:会话开始 / 进入某仓库时,经 hook/MCP **自动注入**最相关、最显著的记忆(而非等 agent 来问)。
- **可治理**:记忆可被人审阅(F22)、修订、过期(F03);显著度由真实使用(F44)驱动。

**非目标**
- 不替代文档(记忆是其上的结构化、可召回层);不做向量训练(用 F26 检索)。
- 不无限增长:低显著度 + 久未召回的记忆自动降权/归档。

## 用户故事

- 作为 agent,我一进这个仓库就自动收到"本项目约定:错误码统一走 X;坑:Y 接口必须先 Z",不必踩坑后才知道。
- 作为维护者,我在收件箱(F22)审阅 agent 新沉淀的记忆,确认或修订。

## 交互设计

```
# 会话开始自动召回(经 hook/MCP)
docky memory · my-app(自动召回 3 条高显著度)
  ⟐ decision  鉴权用 JWT(来源 design/鉴权改造)
  ⚠ gotcha    退款回调需幂等(来源 debug/退款)
$ docky remember --type convention "错误码统一走 AppError"
✓ 已记忆(去重检查:无近似)
```

## 技术落点

- `src/memory.ts`:记忆条目模型(类型/显著度/衰减/来源);显著度取自 F44 使用度,衰减取自 F03。
- 写回:MCP `remember`(走 F20 去重);召回:`recall(project, context)`(复用 F26/F07 检索 + 显著度排序);自动注入经 SessionStart hook(F30 相邻但这是结构化记忆,非指南文件)。
- 审阅复用 F22;过期复用 F03。

## 验收标准

- [ ] 可结构化沉淀/检索记忆条目(类型 + 显著度 + 衰减 + 来源)。
- [ ] MCP `remember` 写回经 F20 去重;`recall` 按相关性+显著度返回。
- [ ] 会话/进入仓库时自动召回高显著度记忆(经 hook/MCP)。
- [ ] 记忆可审阅(F22)、过期(F03);作用域隔离不变。
- [ ] memory 模型与召回排序有单测。

## 衡量指标

- agent"重复踩坑/违反约定"的发生率下降。
- 自动召回的记忆被实际采用的比例;记忆库的显著度分布健康(非无限膨胀)。

## 风险与依赖

- 防记忆膨胀/噪音:显著度 + 衰减 + 人审三重把关。
- 依赖 F44(显著度)、F03(衰减)、F20(去重写回)、F22(审阅)、F26/F07(召回)、hooks(注入)。

## 与其他提案的关系(迭代递进)

- 把 **F07 的"按需检索"** 升级为 **"主动记忆与召回"**,是 docky 面向 agent 的平台级定位。
- 与 **F46(问人)/F48(主动推送)** 同源:F47 让 agent 自动"记得",F48 让人/agent 被"提醒",F46 让人能"追问"。
