# docky UX 优化提案集

> 角色:产品经理(PM)。本目录收录针对 **docky**(面向 AI-agent 辅助开发的集中式文档管理:CLI + MCP + Ink TUI,按 `项目/类型` 隔离作用域)的用户体验优化提案。每条提案是一份可独立评审、可排期的轻量 PRD。

## 路线 · 已交付进度

按轮次(Round)推进,每轮聚焦一个体验断层。截至当前 **已交付 16 项(F01–F15、F20 ✅)**,其余排队中(注:实际实现已领先于本索引——多个后续提案的代码与测试已落地,索引状态待统一回填)。

- **R1 检索闭环** — 打通"找到 → 打开"。**整轮 F01–F05 已交付 ✅**(沉淀基建:`match.ts`、`filterDocs/setStatus/staleDays`、recents/pins、results 模式、`detectScope` 自愈)。
- **R2 全生命周期** — 创建 → 接管 → 协作 → 留痕 → 可逆。
- **R3 深化与规模化** — 深化检索/REPL、批量化、互链织网、受控跨项目。
- **R4 打磨 · 外延 · 治理** — 读得更好、带得出去、配得清楚、查得出问题、写得更干净。
- **R5 纵览与协作** — 纵览整库(洞察/图谱)、治理 agent 产出、固化检索、深化 agent 原生集成。
- **R6 智能 · 主动 · 多端触达** — 语义检索、Web 界面、变更动态、行动项、agent 指南。
- **R7 团队化与生态** — 团队同步、多工作区、文档↔代码、外部通知、脚本化。
- **R8 打磨内功** — 大库性能、健壮自愈、快捷键可发现、无障碍、多语言。
- **R9 深化:内容·协作·维护** — 附件图片、里程碑快照、文档评论、agent 阅读遥测、批量重构。
- **R10 平台化跃迁(对标 Claude Code)** — Ask Docky 问答、agent 记忆层、主动推荐、会话沉淀、SDK 开放协议。
- **R11 平台成熟** — 多 agent 协同、eval 自证价值、知识自愈、企业治理、多模态理解。

> ✅ **数据安全:已收口**:F08(自动提交,写/删先入 git 历史、可回溯)+ F10(软删除入 `.trash/`、覆盖前备份、`undo`/`restore`、删除二次确认)均已交付,删除与覆盖皆可逆。**F20 亦已交付并收口**:agent 侧 `write_doc` 默认 `mode=new` 不再静默覆盖/重复(命中同名或近似即返回建议、不落盘),显式 `replace` 也先把旧内容备份进 `.trash`、可 `docky undo` 还原 → **agent 写入的覆盖保护闭环完成**。
>
> 🔧 **已落地可复用基建**:`match.ts`(F02)→ F13/F14/F12/F20;`filterDocs/setStatus/staleDays`(F03)→ F18/F19/F21/F24;`pageDoc`(F01)→ F16/F23;`detectScope`(F05)→ 上手链路;`SelectableList`(F11)→ browse/results/projects/quickopen 四模式复用。
